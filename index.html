Lightkey 5.9.3

Professional DMX lighting control for discos, nightclubs, live events, and beyond. Command moving heads, scanners, LED matrices, lasers, and any DMX-compatible fixture through an elegant interface. Craft presets, sequences, and cues to deliver stunning light shows. Output up to four DMX universes via USB and Ethernet from DMXking, ENTTEC, Eurolite, and more.

Live Preview

Real-time visualization of all fixtures. Virtual beams accurately simulate pan/tilt, intensity, color, gobos, focus, zoom, iris, shutter/strobe, and prisms for precise control.

Integrated Graphics Editor

Arrange fixtures, add images and shapes effortlessly. Design immersive environments tailored to your venue or event.

Unlimited Shows

Build complex light shows with endless presets, sequences, and cues. Sync timing to music via tap tempo. Create fluid movement paths through custom points.

Live Control

Custom virtual control panels for instant operation. Keyboard shortcuts, Multi-Touch gestures for dimmer, focus, zoom, and iris. Optimized for touch screens and low-light conditions.

Seamless DMX Output

Support for USB interfaces and Art-Net, sACN, ESP-Net devices. Up to 4 universes. Advanced profiles for modern fixtures, including multi-beam LEDs and multiple wheels. Built-in library with 200+ profiles; import SSL2 or FreeStyler.

FAQ

Which DMX interfaces are supported?

USB from DMXking, ENTTEC, Eurolite, Jese, Robe, Stage-Profi, Velleman. Ethernet via Art-Net, sACN, ESP-Net.

Does it support modern fixtures?

Yes. Advanced profiles handle moving heads, multi-beam LEDs, multiple color/gobo wheels. 200+ built-in; import thousands more.

Is it optimized for live use?

Absolutely. Low-light UI, touch controls, keyboard shortcuts, full-screen mode, and Retina support.
